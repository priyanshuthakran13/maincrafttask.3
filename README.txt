MAINCRAFTS INTERNSHIP TASK 3 — NOVA STUDIO
================================================
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Run index.html with the Live Server extension.
4. index.html contains the complete CSS inside a <style> tag, as requested.
5. Other pages use css/style.css.
6. JavaScript is in js/:
   - script.js: navigation, theme, cursor glow, image tilt, reveal animations
   - contact.js: validation and LocalStorage form saving
   - submissions.js: search, delete, clear and CSV export

IMPORTANT:
- Contact form entries are stored only in the same browser's LocalStorage.
- This is a front-end demo; it does not send messages to an email or remote database.
- Images load from Unsplash and require an internet connection.
